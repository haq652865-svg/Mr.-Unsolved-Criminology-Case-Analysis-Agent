# Mr. Unsolved — Criminology Case Analysis Agent

An AI-powered agent for criminology students to analyze 
publicly available unsolved case data and develop investigative thinking.

## Built With
- Flowise (Agent Framework)
- Mistral AI (LLM Backend)

## Features
- Structured investigative thinking framework
- Case theory development support
- OSINT-based research assistance

## How to Use
1. Import the exported flow JSON into Flowise
2. Connect your Mistral AI API key
3. Input case details and let the agent guide analysis
